# Adv. Message Logger

Keep a local journal of edited and deleted messages, keep them visible in chat and compare edits.

- Deleted messages stay in chat, edits show their previous versions.
- Long-press an edited message and choose **Compare edits** to see what changed.
- Journal with search, date filters and saved searches.
- Ignore users, DMs, channels or servers.
- Optional deletion/edit times, with seconds and a 12-hour clock.

Only messages this device received can be logged. Everything stays on the device.

## Install

Add this URL in **Settings → Plugins → Settings Icon → Repository URL**:

```text
https://raw.githubusercontent.com/dariussbezy/dariussbezy-Plugins/main/index.json
```

This repository holds the source and test builds of Adv. Message Logger. All plugins are published together in [dariussbezy's Plugins](https://github.com/dariussbezy/dariussbezy-Plugins).
